# PBE Pro

Windows desktop app for quizing, building, importing, and editing practice quizzes.

## Requirements

- Windows
- [.NET 10 SDK](https://dotnet.microsoft.com/download)

## Build and test

```powershell
dotnet build pbe-pro.sln
dotnet test pbe-pro.sln
```

Run the app from `src/pbe-pro` with `dotnet run`.
